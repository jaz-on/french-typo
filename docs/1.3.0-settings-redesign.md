# 1.3.0: settings page redesign

Branch `1.3.0`, stacked on `1.2.5` (the PR targets `1.2.5` until it is merged).
This version focuses on the settings page: UI, grid, presentation, options and
the features it exposes. Related issues: #18 (contextual help, accessibility),
#27 (settings UI redesign), #14 (file layout).

Status: scoping. No code until the points below are decided.

## Why

- After activation nothing happens until the user picks a spacing mode and saves,
  so the plugin looks inert.
- Six long, stacked sections with dense explanations; no preview of the result.
- The internal key `narrow_space` also drives the regular non-breaking space.
- The restriction by language is off by default, so English content is also
  processed (`What ?`).

## Scope

1. Settings UI: layout and grid, section grouping, contextual help (#18, #27),
   before/after preview, reset button, keyboard and screen reader behaviour
   (RGAA / WCAG 2.1 AA, see `.claude/rules/a11y.md`).
2. Safer defaults at activation: spacing enabled, language restriction on
   "auto" when the site locale is `fr_*`. Behaviour change, to flag in the changelog.
3. Mixed spacing mode: thin non-breaking space before `; ! ?`, regular
   non-breaking space before `:` and inside « ». Needs font compatibility notes.
4. Optional rules, off by default: numbers and units (`10 km`, `1 000`),
   titles (M., Mme), more ordinal forms (1er, 1res, 2es), ellipsis.
5. Detection messages for multilingual plugins that are not detected
   (Weglot, TranslatePress).
6. File layout (#14): option B, move the admin code to `includes/admin.php`
   loaded only in the admin, once the redesign is specified.

## Decisions needed

- Lift the "single file by design" rule of `CLAUDE.md` and `docs/architecture.md`
  for point 6, or keep the single file.
- Design source: a French Typo project in Penpot (design system document, then
  the settings mockups), or a lighter mockup.
- Whether the REST API setting should switch off double processing of fields
  already filtered by `the_content`.

## Out of scope

Straight quotes to « », typographic apostrophe, dashes: too ambiguous to apply
at display time without false positives. Rewriting stored content stays forbidden.
